工具链接：中英文加空格工具

这个工具基于 pangu.js，用于在中文与半角英文、数字之间自动补充合适的空格。

常用排版规则

  • 中文与英文之间增加空格：使用 GitHub 登录。
  • 中文与数字之间增加空格：今天买了 3 个 U 盘。
  • 数字与单位之间增加空格：10 Gbps、2 TB；百分比和度数例外，如 15%、233°。
  • 全角中文标点与相邻文字之间不额外加空格：刚刚买了一部 iPhone，好开心！
  • 专有名词使用官方大小写，例如 GitHub、JavaScript、iOS、macOS。

示例

错误：使用GitHub登录

正确：使用 GitHub 登录

错误：今天买了3个U盘

正确：今天买了 3 个 U 盘

错误：宽带10Gbps，硬盘2TB

正确：宽带 10 Gbps，硬盘 2 TB
